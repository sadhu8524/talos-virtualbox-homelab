# Kubernetes add-ons

This directory is reserved for GitOps-managed cluster add-ons and applications.
A sensible progression is:

1. Cilium and Gateway API
2. Argo CD bootstrap
3. Prometheus and Grafana
4. OpenTelemetry Collector
5. Kyverno or Gatekeeper policies

Keep the base lab small and add each capability in an isolated pull request.
